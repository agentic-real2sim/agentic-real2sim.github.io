This is the codebase for the website showcasing project "Agentic Real2Sim" by PhysAI Lab at UBC.

Follow Coding style and naming conventions in files that already exist in this repository. 

Use the config specified in `.codex/config.toml`. Do not be excessively defensive in programming; use assertions more than try-catch. Assertions should handle most-expected cases. Guarding module imports with try-except is strictly prohibited. If a module is not available, the code should fail immediately with an ImportError.

For git-committing anything, do mention the code is co-authored by the current (human) user and Codex. If you're seeing this as a different agent, e.g. Claude, then say it's co-authored by the current (human) user and that agent.
